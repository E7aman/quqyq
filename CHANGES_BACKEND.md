Ничего не удалено, API только расширен. Старые 38 тестов в этой среде запустить не удалось (нет Django): прогоните `python manage.py test core`.

**Тёплые ответы:** в офлайне перед цитатой живая вводная реплика; отказ теплее и с общими уточняющими вопросами; если человек сам собирается ударить, `safety` — спокойная заметка без номеров. `tools/check_gemini.py` проверяет связь с Gemini.

**П. 4.1 регламента и качество:**
- `kind: concept` + `constitution_articles`: карточки принципов («Закон и порядок», «Адал азамат», «Справедливый Казахстан», обзор шести принципов Указа от 5.11.2025). Если принцип закреплён в Конституции, ответ получает `constitution_refs` и статьи в источниках (проверено: преамбула упоминает идею Справедливого Казахстана и принцип «Закон и Порядок»).
- `tools/eval_questions.py` + `tools/eval_set.json`: 38 вопросов с ожидаемыми статьями, процент попаданий (`--offline` без Gemini). Нашёл и закрыл 4 промаха поиска (религия, выселение, число депутатов, независимость судьи): добавлены синонимы в `konst2026_st25/28/53/78.md` и `tools/keywords_ru.json`.
- `core/gaps.py` + `python manage.py show_gaps`: журнал вопросов без ответа (`LOG_GAPS=1`, обезличенно, по умолчанию выключен).

**Безопасность (аудит):**
- `config/settings.py`: при `DEBUG=0` без `SECRET_KEY` сервер не стартует, `ALLOWED_HOSTS` по умолчанию только localhost (звёздочка осталась лишь для режима разработки); добавлена защита от встраивания сайта в чужие страницы (`XFrameOptionsMiddleware`).
- `POST /api/analyze/`: тип файла сверяется по первым байтам (JPEG, PNG, WEBP, PDF), а не только по заголовку от браузера.
- `@csrf_exempt` на POST-ручках оставлен осознанно: вход по токену в заголовке `Authorization: Bearer`, cookie для авторизации не используются, поэтому CSRF-атака неприменима. Это стоит одной фразой сказать на защите.
