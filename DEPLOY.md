# Деплой на Render

1. Залейте папку `quqyq/` (где лежат `backend/`, `frontend/`, `Dockerfile`, `render.yaml`) в GitHub-репозиторий.
   `.env`, `venv/`, `db.sqlite3` в репозиторий попадать не должны (они в `.gitignore`).
2. Render → New → Blueprint → выберите репозиторий. Он создаст сервис `quqyq-ai` и базу `quqyq-db` из `render.yaml`.
3. Когда попросит, впишите `GEMINI_API_KEY`. Остальные переменные уже заданы.
4. После деплоя откройте `https://<имя>.onrender.com`. Проверка: `/api/health/` должен вернуть `{"ok": true, ...}`.

Ограничения бесплатного тарифа: сервис засыпает через 15 минут без трафика (первый запрос после сна ~1 минута,
комнаты суда в памяти при этом сбрасываются), бесплатная база живёт 30 дней.
