# База знаний (RAG)

Каждый `.md`-файл (кроме этого README) загружается в поиск. Конституцию РК 2026 создаёт скрипт
`tools/import_constitution.py`, вручную её править не нужно.

Формат своего документа:
```
---
title: Название акта
article: ст. 33
source: Название источника
url: https://...
kind: norm              # norm — текст закона; guide — практическая памятка (не закон); concept — принцип/программный документ (не норма права)
constitution_articles:  # только для concept: статьи Конституции, где это закреплено («33, преамбула»). Бот сам покажет «Закреплено в Конституции»
constitution: false     # true — бейдж «Закреплено в Конституции 2026»
verified: true          # true только если текст сверен с официальным источником
keywords: слова и синонимы на русском и казахском (улучшают поиск по бытовым формулировкам)
---
## Подраздел
Дословный текст нормы.
```
Каждый раздел `## ...` — отдельный фрагмент поиска. Не добавляйте пересказы без сверки.

Памятки (`guide_*.md`) пишите простым языком: что сохранить, куда пожаловаться, куда звонить. Не вставляйте в них статьи и сроки,
которых вы не сверили: для статей используйте `kind: norm` и `tools/import_law.py`.

Карточки принципов (`kind: concept`): `ukaz_2025_principles.md`, `principle_*.md`. Сейчас в них только проверенные факты и ссылки.
Чтобы бот отвечал подробно (п. 4.1 положения), вставьте в `## `-разделы **официальный текст** Указа от 5 ноября 2025 года
«Об утверждении основных принципов, ценностей и направлений внутренней политики РК» (по разделу на принцип), а также Послания
Главы государства. Тексты берите с adilet.zan.kz или akorda.kz, замените `url`, поставьте `verified: true` после сверки.
Не пишите `constitution_articles` по догадке: только если вы сами нашли норму в тексте Конституции.
